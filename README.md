# ygeiognosia.com

Self-owned rebuild of the Wix site www.ygeiognosia.com: a static Next.js export on Cloudflare Pages, plus (Phase 5γ) a few Cloudflare Pages Functions for Viva Smart Checkout. Project rules: `CLAUDE.md`. Changes vs. Wix for the owner: `OWNER-CHANGES.md`.

## Commands

| Command | What it does |
|---|---|
| `npm run dev` | Local dev server (http://localhost:3000) |
| `npm run build` | Image width variants → `next build` → `out/` → link check → Wix-sitemap check |
| `npm start` | Serve `out/` locally (http://localhost:3000) |
| `npm run images` | Rebuild `public/images/*.webp` and `src/content/media-index.json` from the local Wix originals (`archive/media`) |
| `npm run check` | Link check + sitemap check on an existing `out/` |
| `npm run lint` | ESLint |

## Cloudflare Pages settings

- Framework preset: **None** (or "Next.js (Static HTML Export)")
- Build command: `npm run build`
- Build output directory: `out`
- Environment variable: `NODE_VERSION` = `22`
- Production branch: `main` (every push deploys; other branches get preview URLs)

## Content

- `archive/` — verbatim capture of the Wix site (never edited by hand). Large files (HTML, media, video, fonts, screenshots) stay in the local folder only.
- `content/` — what the site is built from: `python3 scripts/build_content.py` = `archive/` + the approved text fixes. Re-run after a re-parse.
- `src/content/site.ts` — menu, header/footer texts, phone, address, opening hours.
- `src/content/media-index.json` — generated by `npm run images`.
- Content pages (`/about-us`, `/people`, `/contact`, the wild-olive and `/orders*` pages) are rendered from their Wix layout: `src/content/pages.ts` (titles, descriptions, extras) + `content/pages/pages/<slug>/layout.json` → `src/app/[page]` → `src/components/wix/WixLayout.tsx`. Re-extract a layout from the local Wix HTML with `node scripts/extract-layout.cjs <local html dir> <local assets dir> pages <slug> …` (writes `archive/pages/pages/<slug>/layout.json`), then `python3 scripts/build_content.py`.

## Media

- Images keep their Wix file id as the name: `archive/media/21375d_<hash>_mv2.jpg` → `public/images/21375d_<hash>_mv2.webp` (max 1920px). Use `media("<file>")` from `src/lib/media.ts`; the build fails if an image is missing.
- Width variants (`*-w640.webp` …) are **not committed**: `scripts/image-variants.mjs` creates them on every build (widths = `next.config.ts` deviceSizes + imageSizes).
- The `/people` background video is re-encoded to 720p (Cloudflare Pages allows max 25 MB per file):
  `ffmpeg -i archive/video/21375d_42e6506a0506417d9a8b4a236fd24e84-1080p.mp4 -an -vf scale=1280:-2 -c:v libx264 -preset veryfast -crf 30 -pix_fmt yuv420p -movflags +faststart public/video/people.mp4`
- Fonts are self-hosted in `public/fonts` (OFL licences next to them). Interim choice until the owner decides: Roboto Condensed (for PF DinText Pro) and Mynerve (for Black Diamond); switch in `src/app/globals.css` only.

## Contact form (Jotform)

The site is static, so the `/contact` form (`src/components/contact/ContactForm.tsx`, Wix look and geometry) posts straight to the Jotform form **«Υγειογνωσία – Επικοινωνία»** (EU servers, id `262993612964066`, in Markos' Jotform account). Jotform stores every message (My Forms → Submissions) and emails a notification to ygeiognosia@hotmail.com (Settings → Emails, reply-to = sender).

- Field names (`q7_input`, `q3_q3_email1`, `q4_q4_textbox2`, `q5_q5_textarea3`) come from the Jotform form. If questions are re-created there, their names change: open the form, inspect the inputs and update `JOTFORM` in the component.
- Spam: a hidden honeypot (`website`, Jotform's own trap) plus Jotform's spam filter.
- CSP (`public/_headers`): `connect-src` and `form-action` allow `https://eu-submit.jotform.com` only.
- Texts: `src/content/contact.ts`.

## Checks

- `scripts/check-links.mjs` fails the build on any broken internal link/asset or any Wix URL. Links to pages of later phases are listed in `scripts/pending-links.txt` and only reported.
- `scripts/check-sitemap.mjs` compares `archive/wix-urls.txt` (every URL of the Wix sitemap) with `out/` and `public/_redirects`. It reports only; from Phase 7 the build runs it with `--strict`.
- `scripts/dev/wix-render.cjs` renders an archived Wix page offline with the original images and fonts at any viewport (reference for visual comparison; needs `playwright`).

## Known limitations

- The online shop is closed (`SHOP.open = false`, `src/content/shop.ts`): catalogue + phone orders; cart and Viva checkout come in Phase 5γ.
- Fonts are interim look-alikes (owner decision pending).
- `/contact` form posts cross-origin (`no-cors`) to Jotform, so the page cannot read Jotform's answer. If Jotform rejects a message (spam filter, the free plan's monthly quota, questions re-created so the `qN_…` names changed), the visitor still sees «sent»; the success text therefore also offers ygeiognosia@hotmail.com. Proper fix: a Pages Function that relays the POST and returns Jotform's real status.
- Blog: YouTube videos show a placeholder (no thumbnail) until clicked, so nothing loads from Google before consent. Thumbnails would need `img-src https://i.ytimg.com` in the CSP, or downloaded copies.
- Blog dates: shown only while the newest post is younger than `DATES_VISIBLE_DAYS` (`src/lib/blog.ts`), checked in the browser by an inline script in the root layout; without JavaScript they stay hidden.
- Blog block geometry (image float/width, button positions, paragraph alignment) comes from `archive/posts-layout.json`, measured on the archived Wix HTML with `scripts/dev/post-layout.cjs`. New posts written outside Wix need their own layout (or none: full width).
- Social preview images (`public/og/post/*.jpg`, 1200×630) are generated on every build by `scripts/og-images.mjs` (not committed).
- Wix text boxes keep their Wix widths; with the interim body font a paragraph sometimes wraps one line later than on Wix (a few px lower, never overlapping).
